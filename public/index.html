Compras de combustible · YPF Súper

Podés registrar primero el importe pagado. Fecha, litros y odómetro pueden quedar pendientes hasta tener el ticket o la foto. Una carga incompleta descuenta caja, pero no se usa para medir consumo ni se asigna a un día/mes.

Si faltan datos, podés completarlos después quitando y volviendo a cargar el registro.
Los costos fijos, gastos puntuales, turnos con odómetro y tickets de nafta se guardan en este navegador, no en el ledger público. El backup JSON incluye estos registros locales. No se sincronizan automáticamente entre PC y celular. Sin odómetro, la nafta se calcula solo sobre km reales con pasajero y se marca parcial.
